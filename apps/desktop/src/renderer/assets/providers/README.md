# Provider logo sources

These six static provider marks were downloaded from the official Models.dev logo assets on 2026-10-25:

- https://models.dev/logos/openai.svg
- https://models.dev/logos/anthropic.svg
- https://models.dev/logos/google.svg
- https://models.dev/logos/openrouter.svg
- https://models.dev/logos/deepseek.svg
- https://models.dev/logos/groq.svg

Each response was HTTP 200 with `image/svg+xml`. Before bundling, each SVG was checked for a bounded size and passive vector elements only: no scripts, event handlers, foreign objects, links, external references, entities, embedded images, or animation. The UI uses an application-owned mapping of these local assets; catalog metadata cannot select asset paths or network URLs. Other catalog providers use initials.
