Allowed communication and dependency paths
  1. Renderer ↔ minimal typed Preload ↔ Main. UI has no direct SQLite, saved-key, Node, provider-client, Utility or debugging access.
  2. Main supervises Utility and sends validated audit/session descriptors. Agent Core owns business orchestration and invokes injected ports; Main owns native security and process supervision.
  3. Browser Runtime executes Playwright/WebMCP inside Utility after Main action/ownership authorization, attaching through authenticated guest-scoped CDP to Main's exact native session.
  4. Utility requests storage and credential capabilities through Main IPC. Main alone calls Persistence/secure storage and writes files/SQLite; Browser Runtime captures/sanitizes evidence and Agent Core verifies it.
  5. Contracts defines validated business/native events and identifiers. Main validates/persists events before relaying them to UI; it is not a separate event-bus service.

Use npm Workspaces with one root coordinating package.json and one root package-lock.json. Workspace manifests declare names/exports/dependencies only when built; no package-local lockfiles, alternative package manager, added app/service/package or build-orchestration platform is introduced.

Exclusive native control

Take Control excludes new automation and waits for a safe checkpoint. Return disables manual input, inspects the current native page and reconciles before continuation. Crash-time control intent and explicit decisions are preserved; stale continuations cannot silently reclaim ownership.

Bounded and private

40 default model steps, 10 minutes including questions/User control, 45-second model requests and 15-second browser actions. At most three provider retries and two browser recoveries; uncertain actions are not replayed. Sensitive values never enter model transcripts or checkpoints; inputs and echoes are masked, with fail-closed privacy bounds.

Trusted execution gates

Exact localhost scope, native action leases and one-operation approvals remain enforced. Unknown writes/manual POST stay blocked; eligible declared local forms can receive one exact endpoint/method allowance. Source packages are not security sandboxes.

Truthful checkpoint

One bounded current/last execution checkpoint is owned by Main. Incomplete restart is read-only Interrupted, never automatic execution or reusable authorization. Atomic replacement retries transient Windows locks; permanent I/O failure stops execution. Full history, Verified Findings and reports remain Slice 4. Deterministic test models exist only in test entries; live authenticated acceptance remains unverified.

Execution limits and the failures we actually handle

Approved defaults: 40 model steps, 10-minute wall-clock budget, 15-second browser/WebMCP action timeout, 45-second model-request timeout and 5-second cleanup deadline. Waiting/User-control time counts; optional token/cost caps apply when measurable.

  • Provider interruption: preserve state, show Reconnecting, retry only the failed model request up to three times within budget; no multiplied SDK retries, tool replay or automatic provider switch.
  • Browser crash: at most two recreations, invalidate stale handles/grants, inspect actual state; restore User or Awaiting Control Decision as required. No safe recovery means Interrupted.
  • Invalid/dismissed questions remain pending. Skip/denial/restriction seeks a safe alternative; no continuation means Blocked with the actual distinct reason.
  • Shutdown, worker/storage failure or budget exhaustion: exclude new work, bounded in-flight handling, Unknown when unestablished, preserve partial Interrupted records and discard temporary secrets. Next launch never auto-runs incomplete history.
